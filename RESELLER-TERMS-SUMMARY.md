# Reseller and Partner Terms Summary

Enterprise reseller rights are not included by default.

The following require explicit written authorization from Groovy:

- Reselling Groovy.
- Sublicensing Groovy.
- Hosting Groovy for third parties.
- Offering Groovy-powered services to customers.
- Managed-service delivery using Groovy.
- Enabling token-consumption billing.
- Adding markup over model provider usage.
- Exporting customer billing events generated by Groovy usage.

Implementation rule:

- `reseller_billing_enabled` must be true in the signed license.
- `token_consumption_billing_enabled` must be true in the signed license.
- UI and API routes must remain hidden or disabled unless both signed flags are present.

Environment variables alone must not enable reseller billing.
